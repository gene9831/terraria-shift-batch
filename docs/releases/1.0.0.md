# Shift Batch 1.0

Configure Shift buying and crafting quantities separately, with defaults of 10 and validated values from 10 to 9999. Native prices, payment, stock and ingredient checks remain in use. Capacity limits account for the item's stack size and recipes producing multiple items.

Optional auto-stow is off by default. When the held stack reaches effective capacity, keep holding Shift and the mouse button over the same shop item or recipe for about 0.3 seconds to move it into personal inventory. Partial fits leave the remainder held; a full inventory never causes a world drop. Optional debug logging is available on the mod's configuration page.

- Windows, Terraria **1.4.5.8**, TerrariaModder Core assembly **0.4.2.0**.
- Install **ShiftBatch-1.0.0.zip**. The runtime package contains only DLL, manifest and LICENSE.
- **ShiftBatch-1.0.0-source.zip** includes source, tests, CI and bilingual documentation.
- **SHA256SUMS.txt** records the SHA-256 hashes of both archives.
- Automated: 272 native/config/quantity/lifecycle/logging assertions, plus packaging and release-validation regressions. The maintainer verified buying, crafting, auto-stow and debug logging in game. Final validation of the downloaded CI release is a separate check.

## 简体中文

Shift 购买数量与制作次数分别配置，默认 10，输入范围 10～9999；沿用原版价格、扣款、库存与材料检查，并根据物品堆叠上限及配方产出数量限制实际操作。

自动收包默认关闭：达到有效容量后，在同一商品或配方上持续按住 Shift 和鼠标约 0.3 秒，物品尝试进入个人背包。只能放下一部分时，余量保留在手中；背包满不会导致物品掉落。模组配置页还提供默认关闭的调试日志开关。

下载 **ShiftBatch-1.0.0.zip** 安装；运行包只含 DLL、manifest 和许可证。源码包包含双语说明、构建脚本、测试和 CI。两个 ZIP 的 SHA-256 位于 **SHA256SUMS.txt**。运行要求为 Windows、Terraria 1.4.5.8、Core 程序集 0.4.2.0。
